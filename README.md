# 챔피언 (Champion)

오프라인에서 AI와 1대1로 싸우는 1인칭 3D 근접 전투 게임입니다. (Godot 4.3)

지금 할 수 있는 것
- **AI와 대결**: 칼을 든 결투사와 1대1. 상대 칼이 빛나면 공격이 온다는 신호예요. 막거나, 맞기 직전에 막아서 튕겨내거나, 옆으로 대시해서 피하세요.
- **연습장**: 허수아비 3개를 마음껏 베어 볼 수 있어요.
- **캐릭터 만들기**: 점수 30점을 능력치 5개(힘, 체력, 민첩, 기술, 지구력)와 특수 스킬 2개에 나눠 써서 나만의 캐릭터를 만들어요. 저장하면 다음에 켜도 그대로예요.
- **무기 4가지와 필살기**: 한손검, 대검, 쌍단검, 창. 무기마다 빠르기, 닿는 거리, 막기 세기가 다르고 필살기가 하나씩 있어요.
- **AI 상대 고르기**: 랜덤 상대, 정해진 상대(검객, 탱커, 암살자, 사냥꾼, 광전사), 거울(내 캐릭터와 똑같은 상대). AI 도 같은 규칙으로 만들어지고 스킬을 씁니다.

## 캐릭터 만들기

| 능력치 | 바뀌는 것 |
| --- | --- |
| 힘 | 공격력, 상대가 막을 때 기력을 더 깎음 |
| 체력 | 최대 체력, 맞았을 때 덜 휘청임 |
| 민첩 | 이동 속도, 대시 거리 |
| 기술 | 공격 속도, 튕겨내기 타이밍 여유 |
| 지구력 | 기력 최대치와 회복 속도 (대시, 공격, 막기, 벽타기, 스킬에 씀) |

능력치는 1~10, 5 가 보통입니다. 특수 스킬도 점수를 먹어서, 강한 스킬을 고르면 능력치가 조금 깎여요.

| 특수 스킬 | 점수 | 키 | 하는 일 |
| --- | --- | --- | --- |
| 벽타기 | 2 | 자동 | 벽 타고 오르기, 벽 달리기 |
| 이중 점프 | 1 | 자동 | 공중에서 Space 한 번 더 |
| 점멸 | 3 | E/R | 누르는 방향으로 순간이동 (그 순간 무적), 쿨타임 6초 |
| 갈고리 | 2 | E/R | 조준한 곳(벽, 지붕, 상대)으로 날아감, 쿨타임 7초 |
| 질풍 | 1 | E/R | 3.5초 동안 이동과 공격이 빨라짐, 쿨타임 12초 |
| 철벽 | 3 | E/R | 1.3초 동안 어느 방향 공격이든 막음 (막기 깨기도 버팀), 쿨타임 14초 |

첫 번째로 고른 스킬이 E, 두 번째가 R 입니다. 숫자는 `scripts/character/character_build.gd` 표에서 바꿀 수 있어요.

## 무기와 필살기

캐릭터 만들기 화면 맨 위에서 고릅니다 (점수를 먹지 않아요). 싸우는 동안 때리고, 맞고, 막고, 튕겨내고, 아슬하게 피하면 화면 아래 **금색 게이지**가 차요. 다 차면 **V** 로 필살기.

| 무기 | 특징 | 필살기 (V) |
| --- | --- | --- |
| 한손검 | 무난하고 빠른 기본 무기 | **회오리 베기**: 한 바퀴 돌며 둘레를 모두 벤다. 막기를 깨뜨림 |
| 대검 | 느리지만 한 방이 크다. 휘두르는 동안 잔매에 끊기지 않고, 막혀도 상대 기력을 크게 깎음. 막기가 튼튼함. 잡기는 서툼 | **대지 가르기**: 뛰어올라 앞쪽 넓게 내리찍는다. 못 막음, 멀리 날려 보냄 |
| 쌍단검 | 아주 빠르고 짧다. 연속 베기가 끝없이 이어짐. 잡기와 회피 반격이 강함. 막기는 약함 | **그림자 습격**: 상대 등 뒤로 순간이동해 두 번 찌른다. 못 막음 |
| 창 | 멀리서 찌르기가 빠르고 강하다. 가까이선 옆 베기가 굼뜸. 차지는 긴 찌르기 | **돌진 찌르기**: 내달리며 꿰뚫는다. 막기를 깨뜨리고 멀리 밀어냄 (난간 밖으로!) |

AI 도 무기를 들고 그 무기답게 싸웁니다 (창은 거리를 두고 찌르기, 쌍단검은 바짝 붙어 잡기, 대검은 내려찍기). AI 의 칼이 **금빛**으로 빛나면 필살기예요. 막지 말고 대시로 피하세요. 숫자는 `scripts/combat/weapons.gd` 표에서 바꿀 수 있어요.

## 게임 받아서 실행하기 (Windows)

1. 이 저장소의 **Releases** 에서 `최신 빌드` 를 열고 `Champion-Windows.zip` 을 받습니다.
   (아직 Releases 에 없으면 **Actions** 탭 → 가장 위의 `게임 빌드` → 아래쪽 **Artifacts** 의 `Champion-Windows` 를 받으세요. GitHub 로그인이 필요합니다.)
2. 압축을 풀고 `Champion.exe` 를 더블클릭합니다.
3. Windows 가 "PC 보호" 창을 띄우면 **추가 정보 → 실행** 을 누르세요. (서명이 없는 개인 게임이라 처음에만 뜹니다.)

## 조작법

| 키 | 동작 |
| --- | --- |
| W A S D | 이동 |
| Shift (+ 방향키) | 누른 방향으로 순간 대시, 방향키 없으면 뒤로 (대시 중엔 공격을 피함). 누르고 있으면 달리기 |
| Space | 점프 |
| 마우스 | 둘러보기 |
| 왼쪽 클릭 연타 | **연속 베기** 3단 (왼쪽→오른쪽, 오른쪽→왼쪽, 크게 휩쓸기. 세 번째에 상대가 휘청) |
| 왼쪽 클릭 길게 | **차지 베기**: 누르고 있으면 칼이 빛나며 힘이 모이고, 떼면 돌진하며 벤다. 끝까지 모으면 막기를 깨뜨림 |
| Q | 내려찍기 (느리지만 강하고, 상대의 막기를 깨뜨림) |
| 오른쪽 클릭 (누르고 있기) | 막기. 맞기 직전에 누르면 **튕겨내기** → 상대가 크게 흔들려 반격 기회 |
| 대시로 아슬하게 피한 직후 왼쪽 클릭 | **회피 반격**: 화면 테두리가 푸르게 빛나는 동안 누르면 막을 수 없는 빠른 반격 |
| E / R | 특수 스킬 (화면 오른쪽 아래 칸에 쿨타임이 보임) |
| V | 무기 필살기 (아래 금색 게이지가 다 찼을 때) |
| Esc | 메뉴 |

맞으면 **경직**: 약한 공격엔 움찔, 강한 공격(세 번째 베기, 차지, 내려찍기, 반격)엔 크게 휘청입니다. AI 도 똑같이 적용됩니다.

## 폴더 구성

- `scenes/main.tscn` 게임 시작 장면
- `scripts/main.gd` 연습장 (하늘, 바닥, 울타리, 나무, 허수아비 배치)
- `scripts/player.gd` 플레이어 (아래 몸: 이동/시점, 위 몸: 행동 상태)
- `scripts/duelist.gd` AI 결투사 (판단: 공격 고르기, 막기, 피하기, 반격)
- `scripts/combat/move_set.gd` **동작 표**: 모든 공격의 시간, 피해, 경직, 칼 자세. 새 기술/무기는 여기에 추가
- `scripts/combat/weapons.gd` **무기 표**: 무기마다 동작을 어떻게 바꾸는지, 필살기, AI 버릇, 무기 모양
- `scripts/combat/state_machine.gd` 행동 상태 기계 (가만히, 막기, 공격, 차지, 대시, 경직...)
- `scripts/character/character_build.gd` **캐릭터 규칙**: 능력치, 특수 스킬, 점수, 정해진 상대, 저장
- `scripts/combat/skill_kit.gd` 특수 스킬 쿨타임/기력/질풍 (플레이어와 AI 공용)
- `scripts/ui/build_editor.gd` 캐릭터 만들기 화면
- `scripts/combat/body_rig.gd` 3인칭 몸과 움직임 (아래 몸 / 위 몸 / 흔들림 세 겹을 합침)
- `scripts/fx.gd` 불꽃, 파편 효과
- `scripts/dummy.gd` 허수아비 (맞으면 흔들림, 체력, 쓰러졌다 다시 일어남)
- `scripts/hud.gd` 화면 표시 (조준점, 기력, 기록, 시작 화면)
- `scripts/lowpoly.gd` 각진 로우폴리 모양을 만드는 도우미
- `scripts/sfx.gd` 임시 효과음
- `fonts/` 한글 글꼴 (나눔고딕, OFL 라이선스)
- `tests/smoke_test.gd` 자동 점검 (허수아비 베기 + 자동 조종으로 AI와 대결)
- `.github/workflows/build.yml` 자동 점검, Windows 실행 파일, 웹 버전 빌드

## 개발자용

Godot 4.3 에디터에서 `project.godot` 을 열면 됩니다. 자동 점검:

```
godot --headless --fixed-fps 60 -s res://tests/smoke_test.gd
# 대결만, 막지 않는 자동 조종으로:  ... -- only=duel bot=masher seed=3
# 대시로 피하고 반격하는 자동 조종:  ... -- only=duel bot=dodger
# 상대 캐릭터 바꾸기:  ... -- only=duel preset=탱커   (내 캐릭터: me=암살자)
# 특수 스킬만:  ... -- only=skills
# 무기 필살기만:  ... -- only=weapons   /  무기 바꿔 대결: ... -- only=duel weapon=spear aiweapon=daggers
# 무기 사진:  godot -s res://tests/weapon_shots.gd -- shots=폴더
# 메뉴/캐릭터 화면 사진:  godot -s res://tests/ui_shots.gd -- shots=폴더
```
